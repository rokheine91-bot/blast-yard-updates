# Blast Yard - downloads and updates

Download the latest **Blast Yard** installer from the
[Releases page](https://github.com/rokheine91-bot/blast-yard-updates/releases/latest): `BlastYard-Setup.exe`.

The game updates itself: when a new version is out, it asks "Update now / Later" at start-up.
Updates are small (only what changed) and signed, so the game only installs genuine Blast Yard updates.

This repository holds only release files; the game source is private.
